Workflow

How to push to Figma

Option 1 — html.to.design plugin:
1. Install "html.to.design" plugin in Figma
2. Open plugin, paste each URL (e.g., relifish.store/design/molecules/seller-card.html)
3. Click "Import" — layers auto-create as Figma frames

Option 2 — Figma Dev Mode MCP:
Install Figma desktop → Preferences → Enable Dev Mode MCP Server → add to Claude config:
{"mcpServers":{"figma":{"url":"http://127.0.0.1:3845/mcp"}}} Then I can push direct.
