Default: border: 1.5px solid var(--v3-border); background: var(--v3-bg); hint text in var(--v3-ink-4).
Focused: border: 2px solid var(--v3-brand); box-shadow: 0 0 0 3px var(--v3-brand-l); label color: var(--v3-brand).
Error: border: 2px solid var(--v3-red); background: var(--v3-red-l); label + helper color: var(--v3-red).
Success: border: 2px solid var(--v3-green); background: var(--v3-green-l); checkmark icon; label + helper: var(--v3-green).
Validation timing: show hint while typing → success on valid → error after blur if invalid.
