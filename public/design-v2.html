Design Principles
What V2 steals from the best
Patterns proven by apps doing 10M+ orders/month.

From Blinkit

  • Colored header (brand presence)
  • Floating cart pill (always visible)
  • Circle "+" add buttons
  • 5-tab bottom navigation
  • Grid product layout

From Zepto

  • Floating search card with depth
  • Delivery ETA in header
  • Category icon strip
  • Swipe-to-manage gestures
  • Free delivery threshold shown

From Zomato/Swiggy

  • Restaurant card with image hero
  • Green rating badge format

  • Reorder button in order history

Real-time Flow (Supabase Websocket)
BUYER
1. Places order → INSERT in orders table
2. Subscribes to channel: buyer-orders-{phone}
3. Gets instant UPDATE events when seller acts
4. Stepper + status update without refresh
SELLER
1. Subscribes to channel: seller-orders-{id}
2. Gets instant INSERT when new order arrives
3. Accepts → buyer sees "Confirmed" instantly
4. Ready → buyer stepper jumps to step 3
Fallback: 30s poll if websocket connection drops. Migration 037 enables realtime on orders table.
