❓ Are there sellers in the buyer's area?
✅ YES — Sellers found Show seller cards sorted by distance. Buyer can browse menus, add items, order/pre-order.
❌ NO — No sellers nearby Show waitlist card → benefits, flow diagram, preference form (phone, area, frequency, fish type, budget) → submits to waitlist → email notification to admin.
❓ Seller is open or closed?
🟢 OPEN Items show "ADD" button. Order status = pending. Seller gets push notification immediately.
🔴 CLOSED If seller accepts pre-orders → items show "PRE-ORDER" button + 🕐 Shop closed tag.
If seller doesn't accept → items show "Closed" (no action).
❓ Item in stock or sold out?
📦 IN STOCK "ADD" button. Stock decremented atomically (DB lock). Order = pending.
📦 SOLD OUT If seller accepts pre-orders → "PRE-ORDER" button + 📦 Out of stock + 🎣 Pre-order available tags.
No stock deducted. Order = pre_order. Seller confirms with morning price.
❓ Seller has schedule slots available?
🗓️ YES — Slots exist Show date/time picker above cart. Buyer picks a slot → order = scheduled with scheduled_for timestamp.
➖ NO — No schedule Normal order flow (no slot picker shown). Order = pending or pre_order.
❓ Delivery or Pickup?
🚚 DELIVERY Buyer must be within seller's delivery radius. Address required (flat + building). Delivery fee applied. Address validated before order.
📦 PICKUP No distance restriction. Seller's pickup location shown. No delivery fee.

7. Technical Safeguards

Stock Management

  • Atomic stock check: create_order_atomic() DB function with FOR UPDATE row lock — no race conditions
  • Stock restore on cancel: restore_order_stock() returns quantity to listing
  • Pre-order: no stock deducted (seller fulfills from next catch)
  • Low stock alert: ⚠️ shown when ≤ 2 units remaining

Security

  • OTP rate limiting: max 5 attempts per 15 minutes, 30-min block after exceeding
  • Service role key: all writes go through API routes with Supabase service key (bypasses RLS)
  • Buyer cancel validation: only owner (buyer_id match) can cancel their own orders
  • Seller order validation: listing ownership verified before status changes

Email (Resend)

  • Order creation → email to buyer + seller
  • Status changes → email to buyer + seller
  • Waitlist submission → email to admin (relifishstore@gmail.com)
  • Welcome email to buyer if they provide email
  • Free tier: sends from onboarding@resend.dev (verify relifish.store domain for custom sender)
